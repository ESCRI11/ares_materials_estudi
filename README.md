# InD Prep

Self-paced study materials covering the technical baseline for the
[MA SUPSI in Interaction Design](https://www.supsi.ch/en/master-interaction-design) —
terminal, git, JavaScript, p5.js, Arduino, digital fabrication, Figma, data, AI.

Written for someone with a design background and no programming experience.

**Live site:** https://escri11.github.io/ares_materials_estudi

## Development

```sh
npm install
npm run dev      # localhost:4321
npm run build    # production build into dist/
npm run preview  # serve the production build locally
```

Pushing to `main` deploys automatically via GitHub Actions.
